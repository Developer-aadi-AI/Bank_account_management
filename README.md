# 🏦 Bank Management System (Python, OOP)

**A console-based banking application built using Python and Object-Oriented Programming principles. The system simulates core banking operations with persistent storage and basic security.**

# 🚀 Features

* Account Creation (Savings / Current)

* Deposit & Withdrawal

* Password-Protected Login

* File-based Data Storage

* Interest Calculation (Savings)

* Overdraft Handling (Current)

# 🧠 Concepts Used

* OOP (Encapsulation, Constructors, Inheritance)

* File Handling

* CLI-based System Design

# ▶️ Run the Project

git clone https://github.com/Developer-aadi-AI/Bank_account_management.git

cd bank-management-system

python main.py

* Built to demonstrate practical OOP implementation and real-world system modeling in Python.
